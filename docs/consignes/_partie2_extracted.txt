1 Projet
On vous demande de développer une application (interface en ligne de commande
ou interface graphique) permettant d’interagir avec la base de données conçue lors de la
Partie 1.
Cette application devra permettre au minimum les opérations suivantes :
Gestion des utilisateurs
— Inscription d’un utilisateur (nom d’utilisateur, email, etc.).
— Connexion à un compte existant.
— Consultation du profil (points, niveau, titre actif).
Gestion des cours
— Consultation de la liste des cours.
— Ajout de nouveaux cours (si autorisé).
Gestion des résumés
— Publication d’un résumé associé à un cours.
— Consultation des résumés d’un cours.
— Modification ou suppression de ses propres résumés.
— Évaluation (note et/ou commentaire) d’un résumé.
Système de points
— Attribution automatique de points lors de certaines actions (publication, évaluation,
etc.).
— Consultation du solde de points.
— Historique des transactions de points.
1
Leaderboard
— Affichage du classement des utilisateurs selon leurs points.
Boutique et éléments cosmétiques
— Consultation du catalogue d’objets cosmétiques.
— Achat d’objets avec des points.
— Consultation des objets possédés.
— Activation d’un badge ou titre.
Votre application devra garantir la cohérence des données en s’appuyant autant que
possible sur le système de gestion de base de données (contraintes d’intégrité, clés étran-
gères, etc.).
Vous pouvez ajouter des fonctionnalités supplémentaires, par exemple :
— Système de commentaires avancé
— Système de signalement/modération
— Résumés versionnés
— Système de récompenses spéciales (bonus, achievements)
2 Création
À partir de votre modèle relationnel, vous devez produire un script SQL DDL permet-
tant de créer :
— Toutes les tables
— Les contraintes d’intégrité (PK, FK, UNIQUE, CHECK)
— Les index pertinents
3 Initialisation
Vous devez fournir un script d’initialisation permettant d’insérer un jeu de données
réaliste (qui vous est fourni) afin de tester votre application :
— Plusieurs utilisateurs
— Plusieurs cours
— Plusieurs résumés avec évaluations
— Des objets cosmétiques
— Des transactions de points

implémenter les requêtes suivantes. Si possible, exprimez-les en SQL, algèbre relationnelle
et calcul tuple. Si ce n’est pas possible, justifiez pourquoi.
Il doit être possible de visualiser les résultats dans votre application.
